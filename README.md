## About

Tracks daily habits with streaks, weekly grids and gentle reminders.

## Features

- React 18 with Vite for instant dev builds
- Clean component structure, no state library needed
- Dark UI with subtle gradients
- Ready to extend with routing and data layers

## Install

```bash
git clone https://github.com/krnlfx/habitharbor.git
cd habitharbor
```

## Usage

```bash
npm install
npm run dev

# production build
npm run build
npm run preview
```
